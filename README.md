# Math Blast

Math Blast is a math game project built with Godot. It is still in development.

## Current status

The project opens in Godot 4.7.2. The Easy single-player flow has been verified from the main menu through question answering and the victory screen. Other difficulties, other modes, and exported builds have not been verified. This folder has no configured export preset or verified public download.

The main menu offers Single Player, Host, Join, Adventure Mode, and Teacher Portal; only the Easy single-player flow is verified. The project also includes Python backup modules, but their connection to the Godot game has not been verified.

## Run the project

1. Open this folder, the one containing `project.godot`, in Godot 4.7.2 or newer.
2. Run the project from the editor.

## Before release

- Verify Medium and Hard difficulty, then verify each additional mode before describing it as playable.
- Configure and test an export preset for the intended platform.
- Test the exported build outside the editor before publishing it.

There is no verified downloadable build or GitHub release yet. The old itch.io URL is not available. A public download page can be added after a build has been exported and checked.
