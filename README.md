# Math Blast

Math Blast is a math game project built with Godot. It is still in development.

## Release status

There is no verified downloadable build or published GitHub release yet. The repository's `codepy-main/export_presets.cfg` is empty. The project has been opened in Godot 4.7.2 and its main menu has been launched, but the full gameplay flow and any exported build still need to be verified.

The project includes Python backup modules, but a working connection from the Godot game to those modules has not been verified.

## Run from source

1. Install Godot 4.7.2 or newer.
2. Clone this repository.
3. Open the nested `codepy-main/` folder in Godot (the folder containing `project.godot`).
4. Run the project from the editor.

A packaged download is not available yet. Export presets and a verified build must be added before platform-specific export instructions can be provided.

## Current project notes

The main menu presents Single Player, Host, Join, Adventure Mode, and Teacher Portal options. Their complete flows have not all been verified. The source includes a timed math-question game loop, but it still needs a full play-through check before this project is described as release-ready.
